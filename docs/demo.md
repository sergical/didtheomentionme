# Demo script

About 60 seconds. Live site: https://didtheomentionme.s-a62.workers.dev

Before you record:

- Use a clean browser window at 1440×900, or a phone.
- Open each link below once, so the frames are in the cache and load fast.
- The share card for each result is at `/og.png` with the same query, if you want a still for the end.

## Shots

1. **Handle search.** Type `maria_rcks` in the Handle tab and press Check.
   "Yes." Theo showed the posts 9 times and read 4 aloud. Click "On screen" on the first card. It opens YouTube in a new tab at the second the post is on screen.
   https://didtheomentionme.s-a62.workers.dev/?handle=maria_rcks

2. **Text search.** Open the Text tab and type `the most beautiful thing i've seen`.
   It finds the same post from words only, with the matched words marked.
   https://didtheomentionme.s-a62.workers.dev/?q=the+most+beautiful+thing+i%27ve+seen

3. **Switch creator.** Open the creator menu in the heading and pick Prime. Search `ThePrimeagen`.
   https://didtheomentionme.s-a62.workers.dev/?handle=ThePrimeagen&source=prime

4. **No match.** Search a handle that is not in any video, for example `nobody_here_42`.
   "Not yet." The page tells you which videos it checked.
   https://didtheomentionme.s-a62.workers.dev/?handle=nobody_here_42

5. **Share.** Go back to the first result and click "Share result" or "Post on X".
